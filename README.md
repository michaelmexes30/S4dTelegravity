# S4dTelegravity

A minimal Python project template that is ready to run locally.

## Features
- Python CLI app
- No external dependencies required
- Installable with `pip install -e .`
- Run as a module or command

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
python -m pip install --upgrade pip
pip install -e .
```

## Run the app

```bash
python -m s4dtelegravity
```

or:

```bash
s4dtelegravity --name "Alice"
```

## Example output

```text
Hello, Alice! S4dTelegravity is ready.
```
